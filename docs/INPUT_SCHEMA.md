## 2. Continuation-Row & Missing-Value Conventions

- **Continuation rows**: Seven polymicrobial infants contribute two isolates each. The second isolate appears immediately after its infant's primary row with blank linkage keys (`ID`, `医院名称`, `入院时间`, `分层`). Modules inherit the 62 infant-level fields (columns `1–43` and `77–95`) from the preceding row while retaining separate isolate-level fields (columns `44–76`: pathogen group, Gram stain, 29 AST fields, ESBL, duplicate pathogen check column).
- **Missing tokens**: Modules recognise blank/NA/N/A/unknown tokens, but handling is field-specific. Regimen `UNK` is an explicit unknown category; Gram `不详` supports the unidentified group; the classic-regimen blank is unmarked; late-window blanks after early death/withdrawal are structurally not assessable. The source tokens are retained before module-specific cleaning.
- **AST tokens**: Single-agent and class AST columns accept `敏感`/`S`, `中介`/`I`, `耐药`/`R`, or blank (`NA`).
- **Macro-region coding (`分层`)**: `一层` = `Municipality`, `二层` = `Eastern`, `三层` = `Central`, `四层` = `Western`.
- **Gestational-age coding (`早产儿分类`)**: `超早产儿` = `Extremely preterm infants` (<28 w), `极早产儿` = `Very preterm infants` (28–31 w), `中晚期早产儿` = `Moderate to late preterm infants` (32–36 w), `足月儿` = `Term infants` (≥37 w).
